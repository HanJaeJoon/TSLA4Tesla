# Play Store 다국가 배포 가이드

앱 내 다국어(i18n)는 코드에 포함되어 자동 적용되지만, 아래 두 가지는 Play Console에서 수동 작업이 필요하다.

## 1. 배포 국가 확대

1. Play Console > TSLA4Tesla > 출시(Release) > 프로덕션 > "국가/지역" 탭
2. "국가/지역 추가"에서 배포할 국가 선택 (전체 선택 가능)
3. 참고: 중국 본토는 Google Play 미지원 지역. 중국어(간체) 리소스는 싱가포르/말레이시아 등 화교권 사용자 대상.

## 2. 스토어 등록정보 번역 등록

1. Play Console > 스토어 등록정보(Store presence) > 기본 스토어 등록정보(Main store listing)
2. 우측 상단 "번역 관리(Manage translations)" > "직접 번역 추가"
3. 언어 추가: 영어(미국) en-US, 일본어 ja-JP, 독일어 de-DE, 스페인어 es-ES, 스페인어(중남미) es-419, 중국어(간체) zh-CN
4. 언어별로 이 폴더의 해당 파일 내용을 붙여넣기
5. 스크린샷은 언어별 업로드 가능 (없으면 기본 언어 스크린샷이 표시됨)

### 글자 수 제한

| 항목 | 제한 |
|------|------|
| 앱 이름 | 30자 |
| 간단한 설명 | 80자 |
| 자세한 설명 | 4,000자 |

### 파일 목록

- `ko-KR.md` - 한국어 (기본)
- `en-US.md` - 영어
- `ja-JP.md` - 일본어
- `de-DE.md` - 독일어
- `es-ES.md` - 스페인어 (es-419에도 동일하게 사용 가능)
- `zh-CN.md` - 중국어 간체

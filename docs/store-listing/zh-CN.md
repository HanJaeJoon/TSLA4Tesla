# 简体中文 (zh-CN)

## 应用名称 (30字符)

TSLA4Tesla - 特斯拉股票计算器

## 简短说明 (80字符)

你的特斯拉股票能买几辆特斯拉？实时股价，立刻算出答案。

## 完整说明 (4,000字符)

TSLA4Tesla 帮你计算：持有的特斯拉（TSLA）股票能买几辆特斯拉汽车。

主要功能:
- 实时获取 TSLA 股价
- 支持全部车型和版本：Model 3、Model Y、Model S、Model X、Cybertruck
- 输入持股数量，立即算出可购买的车辆数
- 显示距离下一辆车还差多少股
- 购买力走势图（1个月/6个月/1年/5年）
- 按实时汇率换算为本地货币
- 离线时使用保存的行情数据
- 支持深色模式

本应用仅供参考，显示的价格和汇率可能与实际市场价格不同。

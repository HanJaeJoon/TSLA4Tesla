## 간단한 설명 (80자)

내 테슬라 주식으로 테슬라 몇 대를 살 수 있을까? 실시간 TSLA 주가로 바로 계산.

## 자세한 설명 (4,000자)

테슬라 주식 계산기 TSLA4Tesla는 보유한 테슬라(TSLA) 주식으로 테슬라 차량을 몇 대 살 수 있는지 계산해 줍니다.

주요 기능:
- 실시간 TSLA 주가 조회 (수동 새로고침, 당겨서 새로고침 지원)
- Model 3, Model Y, Model S, Model X, Cybertruck 전 트림 가격 지원
- 보유 주식의 총 가치와 구매 가능 대수 계산 (원화 환산 병기)
- 다음 1대 구매까지 부족한 주식 수와 금액 안내
- 1개월/6개월/1년/5년 기간별 구매 가능 대수 추이 차트
- 결과를 이미지 카드로 저장하고 공유
- 다크 모드 지원
- 입력값 자동 저장 (앱을 다시 열어도 유지)
- 네트워크가 없어도 저장된 시세 데이터로 사용 가능

이런 분께 유용합니다:
- 테슬라 주식을 모으는 중이고 목표를 차 한 대로 잡은 분
- 지금 주가로 내 주식 가치가 원화로 얼마인지 빠르게 보고 싶은 분
- 모델과 트림별 가격을 주식 수로 환산해 비교하고 싶은 분

이 앱은 투자 참고용 계산기이며 투자 조언을 제공하지 않습니다. Tesla, Inc.와 무관한 비공식 팬 앱으로, Tesla는 Tesla, Inc.의 상표입니다.

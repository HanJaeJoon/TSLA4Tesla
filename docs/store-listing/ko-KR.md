# 한국어 (ko-KR)

## 앱 이름 (30자)

TSLA4Tesla - 테슬라 주식 계산기

## 간단한 설명 (80자)

내 테슬라 주식으로 테슬라 몇 대를 살 수 있을까? 실시간 주가로 바로 계산해 보세요.

## 자세한 설명 (4,000자)

TSLA4Tesla는 보유한 테슬라(TSLA) 주식으로 테슬라 차량을 몇 대 살 수 있는지 계산해 주는 앱입니다.

주요 기능:
- 실시간 TSLA 주가 자동 조회
- Model 3, Model Y, Model S, Model X, Cybertruck 전 모델/트림 지원
- 보유 주식 수만 입력하면 구매 가능 대수 즉시 계산
- 다음 1대까지 부족한 주식 수와 금액 표시
- 1개월/6개월/1년/5년 주가 기준 구매 가능 대수 추이 차트
- 원화 환산 금액 표시 (실시간 환율)
- 오프라인에서도 저장된 시세로 동작
- 다크 모드 지원

투자 참고용 앱이며, 표시되는 가격과 환율은 실제 거래 가격과 다를 수 있습니다.

# 日本語 (ja-JP)

## アプリ名 (30文字)

TSLA4Tesla - テスラ株計算機

## 簡単な説明 (80文字)

あなたのTSLA株でテスラを何台買える？リアルタイム株価ですぐに計算できます。

## 詳しい説明 (4,000文字)

TSLA4Teslaは、保有しているテスラ（TSLA）株でテスラ車を何台買えるかを計算するアプリです。

主な機能:
- TSLA株価をリアルタイムで自動取得
- Model 3、Model Y、Model S、Model X、Cybertruckの全モデル・全トリムに対応
- 保有株数を入力するだけで購入可能台数を即計算
- 次の1台まであと何株必要かを表示
- 購入可能台数の推移チャート（1ヶ月/6ヶ月/1年/5年）
- リアルタイム為替レートによる日本円換算表示
- オフラインでも保存済みデータで動作
- ダークモード対応

本アプリは参考用です。表示される価格や為替レートは実際の取引価格と異なる場合があります。
